# GAVYO — SFX EXPANDIDO (Capítulo 1, terror)

**Este arquivo ZIP é um instalador, NÃO contém os áudios.** O programa cria `sons/` e `GAVYO_SFX_EXPANDIDO_AUDIO_CC0.zip` com os **arquivos de áudio realmente baixados**.

## No Mac

1. Extraia todo o ZIP na pasta Downloads.
2. Abra Terminal e arraste `BAIXAR_NO_MAC.command` para a janela do Terminal, depois dê Enter. Ou execute na pasta extraída: `bash BAIXAR_NO_MAC.command`.
3. O programa busca a lista de arquivos diretamente no GitHub, faz downloads paralelos, valida cada OGG/WAV e cria o ZIP final de áudio.
4. Se falhar, leia `RELATORIO_DOWNLOAD.txt`. Executar novamente retoma os arquivos que já existem.

## No Windows
Extraia e execute `BAIXAR_NO_WINDOWS.bat` com Python 3 instalado.

## O que entra
- Passos em concreto, madeira, pedra e vegetação
- Portas, fechos, rangidos, roupa, objetos, livros e metais
- Impactos e sinos
- Interface e alertas
- Variações experimentais/monstruosas para avaliar (não são dublagem realista)

**A seleção contém várias centenas de arquivos CC0; a contagem exata é exibida ao executar.** Nem todos são adequados ao ambiente escolar. Os sons sintéticos de UI e monstros são extras para avaliação, não recomendação de uso imediato.

## O que NÃO está neste pacote
- Vozes reais dos cultistas e protagonistas
- Cânticos do ritual em português
- Respiração humana convincente (ver fontes adicionais)
- Ambiências longas de escola brasileira noturna

Consulte `FONTES_ADICIONAIS.md` para gravações específicas que exigem escolha manual.
