# Origens e licenças

Arquivos selecionados por `baixar_sons.py`:
- Índice público: https://github.com/Mcamento8/open-game-sfx-index
- Provas de licença por pacote: https://github.com/Mcamento8/open-game-sfx-index/blob/main/ATTRIBUTION.md
- Coleção Kenney: https://kenney.nl/assets/category:Audio — CC0 1.0
- Coleção OpenGameArt: https://opengameart.org — licenças verificadas individualmente pelo mantenedor do índice, indicadas no projeto de origem.

Todo arquivo baixado inclui URL de origem em `MANIFESTO.json`. Créditos não são exigidos para CC0, mas recomenda-se registrar os autores no jogo.

Importante: não usar arquivos de licença CC BY sem a atribuição exigida; este instalador não os inclui.
